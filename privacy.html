Privacy Policy

Last updated: 23 November 2026

Tarih Dosyasi Uploader is used only by the owner of the "Tarih Dosyası" and "YesterFile" YouTube channels.

What data the app uses

With the owner's permission, the app uses the YouTube Data API and YouTube Analytics API to upload and schedule videos, read view statistics and manage comments on the owner's own channels.

Storage and sharing

Access tokens are stored only on the owner's computer. No personal data is sold, shared with third parties or used for advertising. The app does not collect data from other users.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
